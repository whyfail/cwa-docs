# 2026-07-28

## 更新概览

- React SPA 模板：运行时基线从 Node 20/22/24/26 兼容范围收敛到 Node.js 24.18.0（Krypton LTS），同步 CI、类型定义、README、AGENTS 与 `.nvmrc`。
- Vue 3 SPA 模板：运行时基线统一到 Node.js 24.18.0，并将 Node 类型定义从 26.x 对齐到 24.x。
- React SSR 模板：Next.js 运行时与 CI 精确验证版本统一为 Node.js 24.18.0，服务端组件和 hydration 边界保持不变。
- Vue 3 SSR 模板：Nuxt/Nitro 运行时与 CI 精确验证版本统一为 Node.js 24.18.0，服务端渲染边界保持不变。
- 本次验证：四套模板均在本地 Node.js 24.18.0 下通过安装、peer 检查、类型检查、lint、单测、覆盖率、组件测试守卫、生产构建和 Playwright E2E。

## React SPA 模板 (vite_react_init)

### 依赖版本变更

| 依赖或工具 | 旧版本 | 新版本 | 类型 | 影响说明 |
| --- | --- | --- | --- | --- |
| Node engines | `^20.19.0 \|\| >=22.12.0` | `^24.18.0` | toolchain | 统一到 Node 24 Krypton LTS，不再声明 Node 20、22、26 支持。 |
| CI Node | 22 | 24.18.0 | toolchain | CI 与本地推荐版本使用相同补丁版本。 |
| @types/node | 未直接声明，锁文件使用 26.1.0 | 24.13.3 | major | 增加直接开发依赖，使工具脚本与 Vite 配置的类型能力匹配 Node 24 运行时。 |
| .nvmrc | 无 | 24.18.0 | toolchain | nvm/nvm-desktop 可直接切换到模板基线。 |

### 升级内容说明

- Vite 8.1.5 支持 Node `^20.19.0 || >=22.12.0`，Node 24.18.0 位于官方兼容范围内。
- pnpm 11.10.0 要求 Node `>=22.13`，Node 24.18.0 满足包管理器要求。
- React、React DOM、React Router、TypeScript 和其他业务依赖本次无版本变化。

### 模板影响

- 新项目推荐直接使用 `.nvmrc` 指定的 Node 24.18.0。
- 仍使用 Node 20、22 或 26 的现有项目需要先切换运行时，再执行 `pnpm install`。

- Next.js、React、Zustand、TypeScript 和其他依赖本次无版本变化。

### 模板影响

## Vue 3 SSR 模板 (vite_vue3_ssr_init)

### 依赖版本变更

| 依赖或工具 | 旧版本 | 新版本 | 类型 | 影响说明 |
| --- | --- | --- | --- | --- |
| Node engines | `^22.19.0 \|\| ^24.11.0 \|\| >=26.0.0` | `^24.18.0` | toolchain | Nuxt 模板统一到 Node 24 Krypton LTS。 |
| CI Node | 24 | 24.18.0 | toolchain | 从浮动主版本改为精确补丁版本。 |
| @types/node | 26.1.1 | 24.13.3 | major | Nitro、Nuxt 配置和工具脚本类型能力对齐 Node 24。 |
| .nvmrc | 无 | 24.18.0 | toolchain | 本地开发与 CI 使用同一运行时版本。 |

### 升级内容说明

- Nuxt 4.5.0 官方 Node 范围包含 `^24.11.0`，因此支持 Node 24.18.0。
- 浏览器行为继续放在 `.client` 插件、`onMounted` 或 `import.meta.client` 保护中，服务端代码继续留在 `src/server`。
- Nuxt、Vue、Pinia、TypeScript 和其他依赖本次无版本变化。

### 模板影响

- 首次类型检查读取到旧 `.nuxt` 生成物并报告 3 个错误；执行 `nuxt prepare` 重新生成类型后复跑通过，后续测试和构建也会自动生成正确类型。
- Nuxt/Nitro 生产构建、服务端启动、首屏渲染与 hydration E2E 均在 Node 24.18.0 下通过。

## 注意事项

- Node.js 官方发布索引显示 24.18.0 是当前 Node 24 LTS 最新补丁；Node 26.5.0 仍处于 Current 阶段，因此本次未作为生产模板默认版本。
- `engines` 使用 `^24.18.0`，允许后续兼容的 Node 24 LTS 补丁；CI 和 `.nvmrc` 精确固定 24.18.0，保证当前验证可复现。
- React SPA 安装仍提示既有 `intersection-observer@0.12.2` 弃用；Vue SPA 与 Vue SSR 仍提示 6 个既有间接依赖弃用，均不阻塞安装和运行。
- React SSR lint 仍有 3 条、Vue SSR lint 仍有 2 条既有 Tailwind 任意值简化建议，lint 均以 0 退出。
- Playwright WebServer 输出 `NO_COLOR` 被 `FORCE_COLOR` 覆盖的环境提示；Nuxt 构建输出插件耗时提示，均不阻塞测试或生产构建。
